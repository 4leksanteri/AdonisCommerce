# AdonisCommerce — API

The AdonisJS 7 backend. Owns the database, all business logic and every rule
the marketplace enforces.

Setup and the commands for running it live in the [root README](../../README.md);
this app is not meant to be started on its own.

`CLAUDE.md` in this directory documents the conventions that matter here —
where things live, why controllers stay thin, how transformers resolve, and
the rules around money, state machines and migrations.
