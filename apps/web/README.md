# AdonisCommerce — Web

The Next.js 16 storefront and panels. Renders; decides nothing — every rule it
displays is answered by the API.

Setup and the commands for running it live in the [root README](../../README.md);
this app is not meant to be started on its own.

`CLAUDE.md` in this directory points at the two files worth reading before
changing anything here: `AGENTS.md` for this version of Next, and
`HEROUI_AGENTS.md` for the component library.
